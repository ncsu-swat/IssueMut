  Text: I Noticed this while looking intoPR 111346:
```
_Bool test2(int a, int b)
{
        int t = a;
        if (t < b) t = b;
        return t <= a;
}
```
Should be optimized to just:
```
        return a >= b;
```

There is a pattern for constants:
/* MIN (X, C1) < C2 -> X < C2 || C1 < C2  */
But we could do the same when we know C1 == C2 and not constant (for !HONOR_NANS & !HONOR_SIGNED_ZEROS).

    MATCH: [PR111364] Add some more minmax cmp operand simplifications
    
    This adds a few more minmax cmp operand simplifications which were missed before.
    `MIN(a,b) < a` -> `a > b`
    `MIN(a,b) >= a` -> `a <= b`
    `MAX(a,b) > a` -> `a < b`
    `MAX(a,b) <= a` -> `a >= b`
    
    OK? Bootstrapped and tested on x86_64-linux-gnu.
