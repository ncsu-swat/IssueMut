- User: Kewen Lin | Time: 2023-02-17 06:14:12 UTC
  Text: This is an test case issue:

double
testd_cst (vector double vd2)
{
  return vec_extract (vd2, 1);
}

got xxlor on LE but xxpermdi on BE.

The scan insn xxlor is for the high order element, the index is 0 on BE and 1 on LE.

The below diff can fix it:
