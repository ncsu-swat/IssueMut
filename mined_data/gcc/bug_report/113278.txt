- User: Richard Earnshaw | Time: 2024-01-08 18:01:59 UTC
  Text: newlib certainly implements fileno():

libc_a-fileno.o:
00000000 T fileno
         U fileno
libc_a-fileno_u.o:
00000000 T fileno_unlocked
         U fileno

So perhaps the issue is that the prototype is missing (or missing with the default compilation options since it's Posix and I don't think we pass options to enable that by default).  Grepping the source, I suspect the former.

- User: Andrew Pinski | Time: 2024-01-09 03:23:41 UTC
  Text: So for C++, -std=c++98 (and others) are passed which causes __STRICT_ANSI__ to be defined which in turn newlib decides not to enable POSIX functions (via defining _DEFAULT_SOURCE which defines _POSIX_SOURCE).


So confirmed, this is just a testsuite issue and the simple way of fixing this is to add -D_GNU_SOURCE to the command line options which causes the POSIX functions in stdio.h to be declared.
