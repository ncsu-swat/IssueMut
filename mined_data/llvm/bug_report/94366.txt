Issue Title: [clang-cl] Provide implicit declarations of `wmain`
Original Post: clang-cl warns that a declaration is missing for `wmain`:

```console
> clang-cl --version
clang version 17.0.3
Target: x86_64-pc-windows-msvc
```

```c
#include <stdio.h>

int wmain(void) {

}
```
