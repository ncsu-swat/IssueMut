Issue Title: Lacking `f16c` and `avx512fp16` CPU feature strings for half-precision SIMDs
Original Post: GCC conveniently provides the [`__builtin_cpu_supports("f16c")` and `__builtin_cpu_supports("avx512fp16")` used here](https://github.com/unum-cloud/usearch/blob/d718d7b4073a389837a8e4d849bdbc9017962a6d/include/usearch/index_plugins.hpp#L225), to detect the availability of half-precision `float16` SIMD-instructions in x86 CPUs of the AVX2 and AVX-512 generations. Assuming this functionality is becoming more important in rising AI applications, achieving parity with recent GCC versions would be great.

For now, I've [switched to inline Assembly to support a broader range of compilers](https://github.com/unum-cloud/usearch/blob/c872160b031b7e7bf869c6340e78afe21b999f18/include/usearch/index_plugins.hpp#L223). I'm ready to help patch Clang if more people face the issue.

Comment by ecatmur: Relevant locations are https://github.com/llvm/llvm-project/blob/966d564e43e650b9c34f9c67829d3947f52add91/llvm/include/llvm/TargetParser/X86TargetParser.def#L174 (for clang) and https://github.com/llvm/llvm-project/blob/966d564e43e650b9c34f9c67829d3947f52add91/compiler-rt/lib/builtins/cpu_model/x86.c#L144 and https://github.com/llvm/llvm-project/blob/966d564e43e650b9c34f9c67829d3947f52add91/compiler-rt/lib/builtins/cpu_model/x86.c#L746 (for compiler-rt). Note that support for f16c (but not avx512fp16) was added to compiler-rt in https://github.com/llvm/llvm-project/issues/59961 to support microarchitecture level x86-64-v3, but not to clang.

The enumeration https://github.com/llvm/llvm-project/blob/966d564e43e650b9c34f9c67829d3947f52add91/compiler-rt/lib/builtins/cpu_model/x86.c#L103 and the "priority" in https://github.com/llvm/llvm-project/blob/966d564e43e650b9c34f9c67829d3947f52add91/compiler-rt/lib/builtins/cpu_model/x86.c#L103 should each match the gcc feature enumeration https://github.com/gcc-mirror/gcc/blob/9693459e030977d6e906ea7eb587ed09ee4fddbd/gcc/common/config/i386/i386-cpuinfo.h#L154 for binary compatibility with libgcc.

When adding support to clang, it would be preferable to add corresponding support to compiler-rt and to document that a recent version of libgcc is required if using that rtlib, since otherwise the feature flag bit(s) will not have been set in `cpu_features2`.
