Comment by AaronBallman: The root cause of this is that we enabled `thread_local` as a keyword in C23 mode and it is now mapping to the C++ `thread_local` semantics rather than the C11 `_Thread_local` semantics. You can see this in: https://godbolt.org/z/e89MsbG1E
