Issue Title: [llvm-lit][compiler-rt] Test using 'export' failing to execute with lit internal shell due to too many arguments
Original Post: The following RUN line in `compiler-rt/test/asan/TestCases/Posix/high-address-dereference.c` fails when run with lit's internal shell because `export` is given two arguments instead of only one. 
`RUN: export %env_asan_opts=print_scariness=1`

`%env_asan_opts` expands to `env ASAN_OPTIONS`, which is why the test is failing to execute.
