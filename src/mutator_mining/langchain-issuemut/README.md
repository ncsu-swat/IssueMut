### Mutator Generator
- The langchain-based mutator generator should be start thorough executing run_parallel.sh.
  - run_parallel.sh is under scripts folder
- All of the results generated by this module will be placed under results folder
- 5 different mutator folders will be generated after running this tool under results/mutators.
  - all is folder containing all of the mutators regardless of the success of the mutator.
  - correct is a folder containing the mutators that pass all 4 test cases.
  - partial correct is a folder containing the mutators that pass 3 out 4 test cases.
  - wrong folder is a folder containing the mutators that pass less than 3 test cases.
  - error folder is a folder containing the mutators that have invalid sed commands and couldn't be resolved after the refinement iterations.
- All of the generated mutants are under results/temp folder.
  - There is no mutant if there's an error running its corresponding mutators. Therefore, if there's no temp file, there's was an error when running its mutator.
- All of the diff files are under results/diff folder.
  - The diff files are related to the mutators under results/mutators/wrong folder.
