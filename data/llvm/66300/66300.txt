Issue Title: [clang] `-Wmissing-field-initializers` incorrectly emits a warning when the last field of the initialized struct is a flexible array
Original Post: $ cat test.c
```
struct S {
  int f0;
  int f1[];
};

typedef struct S S;

S s = {1, {2, 3}};
```

$ clang -c test.c -Wmissing-field-initializers

    8 | S s = {1, {2, 3}};
