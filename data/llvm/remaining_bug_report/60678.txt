Comment by mgorny: Proposed to mark it XFAIL via https://reviews.llvm.org/D148496.
Comment by MaskRay: When bufsz is too large and `buffer+bufsz` wraps around, `snprintf` printing a string without `%` will have the last char changed to NUL (https://sourceware.org/bugzilla/show_bug.cgi?id=30441). musl requires that `bufsz` cannot be larger than `INT_MAX`. I have a pending patch to update dfsan interceptor to work with glibc 2.37+ and musl.

```
% cat sn.c
#include <stdio.h>
#include <stdint.h>

int main() {
  char str[20];
  snprintf(str, SIZE_MAX, "Hello world!");
  puts(str);
}
% cc sn.c
% ./a.out
Hello world
```
