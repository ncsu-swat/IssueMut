Issue Title: [flang][mlir] complex arithmetic dialect conversion for absolute value is incorrect in face of underflow
Original Post: Test program:
```console
$ cat check.f90
program complex_arithmetic
  implicit none

  integer, parameter :: dp = selected_real_kind(15, 307)
  complex(dp) :: z1, z2, z3
  real(dp) :: abs_z1, abs_z2

  z1 = (1.0_dp, 1.0_dp)
  z2 = (1.0e-300_dp, 1.0e-300_dp)

  ! Divide z1 by z2
  z3 = z1 / z2
  write(*,*) "Result of z1 / z2: ", z3

  ! Calculate absolute values of z1 and z2
  abs_z1 = abs(z1)
  abs_z2 = abs(z2)
  write(*,*) "Absolute value of z1: ", abs_z1
  write(*,*) "Absolute value of z2: ", abs_z2

  ! Check for overflow or underflow in absolute value calculation
  if (abs_z1 == huge(abs_z1)) then
    write(*,*) "Overflow occurred in absolute value calculation of z1"
  endif

  if (abs_z2 == 0.0_dp) then
    write(*,*) "Underflow occurred in absolute value calculation of z2"
  endif

end program complex_arithmetic
```

Comment by kiranchandramohan: The complex dialect conversion to standard is not precise and does not consider underflows.
https://github.com/llvm/llvm-project/blob/b58a58c3b1c0dbaf75b00899a0db42a62c8f58e1/mlir/lib/Conversion/ComplexToStandard/ComplexToStandard.cpp#L29

Use `-mmlir --math-runtime=precise` or `-mmlir -disable-mlir-complex` to workaround the issue.

Comment by Leporacanthicus: To produce MLIR from flang-new, you can use `flang-new -fc1 -emit-mlir source.f90`.
Comment by k-arrows: See "ALGORITHM 312 ABSOLUTE VALUE AND SQUARE ROOT OF A COMPLEX NUMBER" in the following:
https://dl.acm.org/doi/pdf/10.1145/363717.363780

`SqrtOpConversion` follows this but `AbsOpConversion` does not.
The following mock shows that we can avoid (unnecessary) overflow and underflow.
```c
#include <iostream>
#include <cmath>

void myabs1(double real, double imag)
{
    std::cout << sqrt(real * real + imag * imag) << std::endl;
}

void myabs2(double real, double imag)
{
    if(real == 0)
    {
        std::cout << imag << std::endl;
    }
    else if(imag == 0)
    {
        std::cout << real << std::endl;
    }
    else
    {
        if(real > imag)
        {
            imag /= real;
            std::cout << real * sqrt(1 + imag * imag) << std::endl;
        }
        else
        {
            real /= imag;
            std::cout << imag * sqrt(1 + real * real) << std::endl;
        }
    }
}

int main(void)
{
   double x = 1.0e300;
   double y = 1.0e-300;

   myabs1(x, x);
   myabs1(y, y);
   myabs2(x, x);
   myabs2(y, y);
}
```

```console
$ clang++ -Wall -Wextra myabs.cpp
$ ./a.out
inf
0
1.41421e+300
1.41421e-300
```
