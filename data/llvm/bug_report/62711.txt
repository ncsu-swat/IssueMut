Issue Title: clang-15 crashes on __builtin_va_arg
Original Post: The bug triggering testcase:
$ cat small.c
```c
#include <stdarg.h>
#include <stdlib.h>

void vat(va_list param, ...) {
  va_list local;

  __builtin_va_start(local, param);

  if (__builtin_va_arg(global, int) << 1) abort();
}
```
