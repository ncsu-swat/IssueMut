Issue Title: Crash issue when using flexible array member in struct S
Original Post: 
This crash can be observed in both LLVM 19 and LLVM trunk versions. （https://godbolt.org/z/d45oWKvaK）
# Command
`clang++ bug.cpp`

# Code
```cpp
struct S { char x[]; };

void
foo (struct S *x, struct S *y, struct S *z)
{
  __atomic_exchange (x, y, z, __ATOMIC_SEQ_CST);
}
```

Comment by MitalAshok: https://github.com/llvm/llvm-project/blob/b2c9f7d3188e41163574a83a835437955cf4b80f/clang/lib/CodeGen/CGAtomic.cpp#L843

`sizeof(S) == 0` which is what causes the issue. GCC has an error for this <https://godbolt.org/z/b8MT1d1zM>:

```
error: argument 1 of '__atomic_exchange' must be a pointer to a nonzero size object
```

I assume other atomic functions are also affected.
