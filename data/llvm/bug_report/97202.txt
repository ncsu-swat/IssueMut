Comment by AaronBallman: C23 6.4.5p6: "... For UTF-8 string literals, the array elements have type char8_t, and are initialized with the characters of the multibyte character sequence, as encoded in UTF-8. ..."

C23 7.30p3: "... char8_t which is an unsigned integer type used for 8-bit characters and is the same type as unsigned char; ..."

We get it right for character literals (N2418), but not string literals (N2653): https://godbolt.org/z/8oad889GK

(Note, we claim to conform to N2418, we don't claim to conform to N2653 yet.)
