Issue Title
    : [OpenMP RT] Passive policy with dist barrier does not end Original Post
    : ```c
    // clang -fopenmp t1.c -o t1 && OMP_WAIT_POLICY=passive
    // KMP_FORKJOIN_BARRIER_PATTERN='dist,dist' ./t1
    void
    test_omp_barrier() {
#pragma omp parallel
  {
#pragma omp task
    {}
  }
}

int main() { test_omp_barrier(); }
``` It seems to be a simple parallel with tasks and passive policy
            does not allow the dist barrier to progress and
        finish the execution.Removing passive or
    changing the barrier pattern makes the program work again.
