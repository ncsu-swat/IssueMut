Issue Title: [LoongArch] An error when cross using clang++ and g++
Original Post: - Testcase

```
// foo.h 
struct A { };
int foo(A a, int i);
```

```
// foo.cpp
#include "foo.h"
int foo(A a, int i) {
  return i;
}
```

```
// main.cpp
#include "foo.h"

int main() {
  A a;
  return foo(a, 5);
}
```

- Compile and run

```
$ g++ -c foo.cpp -o foo.o
$ clang++ -c main.cpp -o main.o
$ ./main 
# Expected output is 5, but actual output is a random number.
$ echo $?
120
```

```
$ g++ --version

```
