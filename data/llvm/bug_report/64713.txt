Issue Title: Clang hangs up for an obscure though valid function declaration
Original Post: The compilation of the C code below hangs forever for clang's version >= 15. See [godbolt](https://godbolt.org/z/89rh5Ydae).

```
typeof(int(int)) x;
```

The code is equivalent to:

```
int x(int);
```

When compiled in C23 mode (`-std=c2x`) where `typeof` is a keyword then a following error message is produced.

```
error: expected function body after function declarator
```

The error message is incorrect because AFAIK the code is strictly compliant to C23 standard.
