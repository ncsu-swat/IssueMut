Comment by thurstond: tl;dr The "random" stack tag is sometimes zero, as would be expected roughly 1/256 times. In such cases, the buffer overflow is not caught, because the corresponding tag memory is also zero.

## How the stack base tag is generated

https://github.com/llvm/llvm-project/blob/main/llvm/lib/Transforms/Instrumentation/HWAddressSanitizer.cpp#L1145
```
Value *HWAddressSanitizer::getStackBaseTag(IRBuilder<> &IRB) {
...
  // Extract some entropy from the stack pointer for the tags.
  // Take bits 20..28 (ASLR entropy) and xor with bits 0..8 (these differ
  // between functions).
  Value *StackPointerLong = IRB.CreatePointerCast(StackPointer, IntptrTy);
  Value *StackTag =
      IRB.CreateXor(StackPointerLong, IRB.CreateLShr(StackPointerLong, 20),
                    "hwasan.stack.base.tag");
  return StackTag;
```

Since it's XORing against ASLR entropy, we would expect the result to occasionally be zero, just by chance.

## Empirical demonstration

I modified the test case to print out the address of the out-of-bounds access:

```
// RUN commands omitted for brevity - same as the original test case

__attribute__((noinline)) void FUNC2() { int x; USE(&x); FUNC1(); }
__attribute__((noinline)) void FUNC3() { int x; USE(&x); FUNC2(); }
__attribute__((noinline)) void FUNC4() { int x; USE(&x); FUNC3(); }
```

Comment by thurstond: Why tests are extra-flaky with `-hwasan-record-stack-history=libcall`: the stack base tag is fully randomized, hence stack tags may occasionally be zero. I plan to add the zero-tag workaround to the tests that use this option (stack-history-length, stack-uas).

When the alternative option (`-hwasan-record-stack-history=instr`) is selected, the StackBaseTag is obtained from a value that is not fully randomized.

https://github.com/llvm/llvm-project/blob/main/llvm/lib/Transforms/Instrumentation/HWAddressSanitizer.cpp

```
void HWAddressSanitizer::emitPrologue(IRBuilder<> &IRB, bool WithFrameRecord) {
  switch (ClRecordStackHistory) {
    case libcall: {
        ...
        break;
    }
    case instr: {
      ThreadLongMaybeUntagged = getThreadLongMaybeUntagged();

      StackBaseTag = IRB.CreateAShr(ThreadLong, 3); // This prevents the full randomization of stackBaseTag
    }
    case none: {
      llvm_unreachable("A stack history recording mode should've been selected.");
    }
```
