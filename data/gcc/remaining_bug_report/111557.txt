- User: Lasse Collin | Time: 2023-09-23 19:31:09 UTC
  Text: The RISC-V C API Specification[1] has __riscv_misaligned_fast, __riscv_misaligned_slow, and __riscv_misaligned_avoid. The commit 6e23440b [2] used "unaligned" instead of "misaligned" though. The spelling __riscv_unaligned_* was mentioned in [3] but in [4] it was changed to __riscv_misaligned_*.

Clang doesn't have these macros yet but there is a recent pull request[5] that uses the __riscv_misaligned_* spelling.
