in the inner loop where we have the zero distance.  We're re-ordering

      d[c + 1] = b = d[c];
      d[c].a = 0;           (A)
      d[c + 1] = b = d[c];  (B)
      d[c].a = 0;

as

      d[c + 1] = b = d[c];
      d[c + 1] = b = d[c];
      d[c].a = 0;
      d[c].a = 0;

breaking the dependence between (A) d[c].a = 0; and (B) b = d[c].a;

Note there's a dependence in both directions in the unrolled form.
