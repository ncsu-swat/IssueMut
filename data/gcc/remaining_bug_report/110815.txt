  Text: C code increasingly uses

void foo(char buf[static 10]);

to indicate that buf is a non-null pointer.

GCC already has some warnings for this but all you would get with the nonnull attribute. In particular, -Wnonnull-compare is missing. 


void
foo (int a[static 1])
{
  if ((void*)0 == a)  // should warn
    return;
