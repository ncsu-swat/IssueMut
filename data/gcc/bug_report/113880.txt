- User: Andrew Pinski | Time: 2024-02-11 22:46:43 UTC
  Text: Take:
```
void f(float *a, double *b)
{
        b[0] = a[0];
        b[1] = a[1];
}
```

This should be optimized to:
```
        ldr     d31, [x0]
        fcvt    v31.2d, v31.2s
        stp     q31, [x1]
        ret
```

But V2SF->V2DF conversion does not exist.

This is in a similar way V4HF->V4SF is missing (PR 113869).
