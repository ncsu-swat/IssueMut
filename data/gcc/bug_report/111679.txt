- User: Andrew Pinski | Time: 2023-10-03 16:11:40 UTC
  Text: Take:
```
int f(int a, int b)
{
        return a | ((~a) ^ b);
}

int f1(int a, int b)
{
        return (~a) | (a ^ b); // ~(a & b) or (~a) | (~b)
}
```

The only difference between these 2 functions is a is bitwise inversed. f is able to be detected and simplified but not f1.

I Noticed this while working onPR 111282.

- User: Andrew Pinski | Time: 2023-10-05 04:15:00 UTC
  Text: ```
/* (~a) | (a ^ b)  -->  (~a) | (~b)
   (which might be done into ~(a & b) depending on if ~a is not a cmp)  */
(simplify
 (bit_ior:c @0 (bit_xor:c @1 @2))
 (with { bool wascmp; }
 (if (bitwise_inverted_equal_p (@0, @1, wascmp)
      && (!wascmp || element_precision (type) == 1))
  (bit_ior @0 (bit_not @2)))))
```

Still need some testcases.
