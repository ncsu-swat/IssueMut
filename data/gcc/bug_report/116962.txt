- User: Nicolas Savoire | Time: 2024-10-03 23:30:49 UTC
  Text: The following C code:

__attribute__((naked)) void foo() { asm("ret"); }


compiled with -O0 -fstack-protector-all -S on x86_64 results in:

foo:
	movq	%fs:40, %rax
	movq	%rax, -8(%rbp)
	xorl	%eax, %eax
	ret
	nop
	movq	-8(%rbp), %rax
	subq	%fs:40, %rax
	je	.L2
	call	__stack_chk_fail
.L2:
	ud2

Generated code seems wrong since "movq	%rax, -8(%rbp)" will overwrite a value in the previous frame.
