- User: Andrew Pinski | Time: 2023-04-09 02:20:29 UTC
  Text: The issue is related to struct foo in the function declaration.

With a slightly modified code you can get an ICE instead:
int bar(int n, struct foo *x)
{
        int a = n;
        struct foo { char buf[a++]; }* p = x;
        return n == a;
}

int main()
{
    return bar(1, 0);
}
