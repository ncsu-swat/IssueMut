    with this following code:
    -      if (TARGET_MIN_VLEN < 128 && TARGET_MAX_LMUL < RVV_M2)
    -       return word_mode;

    TARGET_VECTORIZE_RELATED_MODE
    TARGET_VECTORIZE_AUTOVECTORIZE_VECTOR_MODES

    which is ugly approach and too much codes change.
