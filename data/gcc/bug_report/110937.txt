  Text: Take:
```
_Bool f2(_Bool a, _Bool b)
{
        if (a)
          return !b;
        return b;
}
```
This should be optimized to just:
```
_Bool f2_(_Bool a, _Bool b)
{
  return a ^ b;
}
```
