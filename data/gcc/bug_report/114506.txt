- User: JuzheZhong | Time: 2024-03-28 10:49:12 UTC
  Text: (In reply to Andrew Pinski fromcomment #2)> Using -fno-vect-cost-model forces the use of M8 though.
> 
> I have no idea how this cost model is trying to prove here.We shouldn't force M8.

We have support dynamic LMUL cost model heuristically analyze the vector register
pressure in SSA level. So that we could pick the optimal LMUL.

This PR presents shows that RVV dynamic LMUL cost model pick LMUL 4 instead of LMUL 8 unexpectedly.

So we should adjust the dynamic LMUL cost model to fix this issue.

    RISC-V: Refine the condition for add additional vars in RVV cost model
    
    The adjacent_dr_p is sufficient and unnecessary condition for contiguous access.
    So unnecessary live-ranges are added and result in smaller LMUL.
    
    This patch uses MEMORY_ACCESS_TYPE as condition and constrains segment
    load/store.
    
    Tested on RV64 and no regression.PR target/114506gcc/ChangeLog:
    
            * config/riscv/riscv-vector-costs.cc (non_contiguous_memory_access_p): Rename
            (need_additional_vector_vars_p): Rename and refine condition
